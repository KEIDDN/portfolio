# Miki Herrero — Portfolio

Personal portfolio of Miki Herrero, Product Designer (Creative Technology & AI) and founder of OXIA Labs.

- Next.js (App Router) · React Three Fiber · GSAP · Lenis
- Bilingual: `/en` (default) and `/es`
- Content lives in `src/content/` (`projects.ts`, `i18n.ts`); media in `public/work/<project>/`

```bash
npm install
npm run dev
```

Fonts: Garet (Spacetype, personal-use licence) in `public/fonts`.
